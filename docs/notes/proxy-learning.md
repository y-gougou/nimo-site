# 梯子学习笔记：从零开始的科学上网

> 这篇笔记记录我从"一窍不通"到"能自己排查问题"的过程。
> 内容包括：为什么要用代理、Clash 系客户端怎么配、DNS 覆写是什么、常见坑怎么排。

## 1. 为什么会需要"梯子"

有些网站（Google、OpenAI、Telegram……）在中国大陆无法直接访问。原因不是技术问题，而是网络出口被限制。

这时就需要**代理（Proxy）**：把你的网络请求先发到一个海外的中转服务器（"节点"），由它替你访问目标网站，再把结果传回来。

```
你的电脑 → 代理节点（海外） → 目标网站
```

## 2. 几个核心概念

| 概念 | 说明 |
|------|------|
| **节点** | 海外的中转服务器，分布在各个国家和地区 |
| **订阅** | 机场（代理服务商）给你的配置链接，导入客户端后自动获得节点列表 |
| **客户端** | 管理节点、转发流量的软件，如 Clash Party、Clash Verge、追云等 |
| **协议** | 节点与客户端之间的通信方式，如 Hysteria2、VLESS、Shadowsocks 等 |

## 3. 我的客户端：Clash Party

Clash Party（包名 mihomo-party）是一个开源的 Clash 图形客户端，基于 Mihomo 内核。

### 3.1 首次配置流程

1. 打开客户端，进入 **配置（Profiles）** 页
2. 点击 **新增**，粘贴机场给你的**订阅链接**（https:// 开头）
3. 启用该配置，客户端自动下载节点列表
4. 到 **代理（Proxies）** 页选择节点
5. 开启系统代理或 TUN 模式

### 3.2 关键开关：DNS 覆写（Override DNS）

**建议开启。** 原因：

- **防 DNS 泄露**：不开时，应用可能直接用运营商 DNS 解析海外域名，暴露访问记录，还可能被判定"地区不支持"（比如 ChatGPT 登录 403）
- **fake-ip 模式依赖它**：Clash 默认用 fake-ip 增强模式，需要内核接管解析才能正确分流
- **防污染**：运营商 DNS 对海外域名可能返回污染结果，覆写后走 DoH 加密查询拿到真实 IP

### 3.3 模式选择

- **规则模式（Rule）**：按规则分流，国内直连、国外走代理。日常推荐
- **全局模式（Global）**：所有流量都走代理。注意选择器里别拨到 **DIRECT**（直连），否则国外流量在"裸奔"——这个坑我踩过
- **直连（Direct）**：不走代理，仅用于测试

## 4. 排查问题的一般思路

遇到"上不了网"时，按顺序检查：

```bash
# 1. 客户端进程在不在
pgrep -af -iE 'clash|mihomo'

# 2. 代理端口有没有监听
ss -tlnp | grep 127.0.0.1

# 3. 通过代理访问，看出口 IP 和地区
curl -x http://127.0.0.1:7890 https://api.ip.sb/geoip

# 4. 直连对比（判断是不是网络被墙）
curl -s -m 10 https://www.baidu.com -o /dev/null -w "%{http_code}\n"
```

### 常见坑清单

| 症状 | 原因 | 解法 |
|------|------|------|
| 浏览器报"代理服务器地址有问题" | 系统代理指向的端口没服务（换了客户端端口变了） | 改系统代理端口，对齐客户端实际监听端口 |
| ChatGPT 登录 403 "Country not supported" | 出口节点 IP 被 OpenAI 拉黑（机房段） | 换干净节点（美/日/新加坡主流机房） |
| Telegram 连不上 | TELEGRAM_PROXY 还指向旧端口 | 更新环境变量里的代理端口 |
| 全局模式还是打不开外网 | 模式选择器拨到了 DIRECT 直连 | 切到正确的代理组 |
