          03 · Quick Reference
          
            
          只记最常用的
          
          
          
          
          不追求覆盖全部命令，只保留日常最容易忘、又最能改变工作效率的操作。
          
        
          

        
          
          
          
            
          交互快捷键
          
            
          @搜索并引用项目文件
          
            
          Shift + Tab切换 Plan 模式
          
            
          Tab工作中把指令排到下一轮
          
            
          Enter工作中立即注入纠偏信息
          
            
          Ctrl + G打开编辑器编写长任务
          
            
          Ctrl + R搜索提示词历史
          
            
          !在当前沙箱中运行 Shell 命令
          
          
          

          
          
            
          终端入口
          
            
          codex -C 路径从指定项目目录启动
          
            
          codex --search需要最新资料时启用实时搜索
          
            
          codex --image 图像附加报错截图、波形或界面参考
          
            
          codex resume恢复保存的会话
          
            
          codex review --uncommitted审查尚未提交的修改
          
            
          codex doctor诊断安装、登录、Git和配置
          
            
          codex exec "任务"执行稳定、可重复的非交互任务
          
          
          
        
          

        
          
          任务公式
          目标 Goal+
          上下文 Context+
          约束 Constraints+
